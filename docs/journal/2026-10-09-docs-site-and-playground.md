# 2026-10-09: Docs site and playground

## Request

The request was a Vercel-deployable docs site with the ability to try the
library in the browser. Scope agreed in review of the PR:
- render the docs into a static site;
- deploy the site on Vercel;
- a minimal playground: edit a document and watch the diagram and relation
  update, plug sub-terms into stars, share the result.

## Decisions

1. **No site framework.** `site/build.mjs` (≈200 lines, one dependency: `marked`)
   renders the existing markdown. The docs stay readable on GitHub and
   become pages on the site, with no second copy to maintain. Links are
   written for GitHub (`theory.md#…`) and rewritten at build time.
2. **The build checks links.** Every relative link must reach a file in
   `dist/`, and every `#fragment` a heading on the target page. Heading ids
   follow GitHub's algorithm, so one set of anchors works in both places.
3. **The playground is a mode of the viewer, not a second app.** One page, one
   renderer. `?edit` opens a JSON editor column. The editing operations are
   pure functions on JSON documents in `viewer/edit.js`, tested in Node. That
   keeps the DOM layer thin.
4. **Plug-in uses the paper's plug-and-play (§5.1).** The pluggable pieces are
   every labelled sub-term of the examples, each with its leaf relations. An
   OR-from-NAND example was added so that three different gates (AND, OR,
   XOR) fill a NAND-shaped star `{A, B, out}`.
5. **Edits keep the algebra consistent.** Leaf relations are spliced with the
   term. Collapsing a sub-term gives the leaf the relation the sub-term
   computes, and `expected` is recomputed. An edited document is retitled
   "(edited)", because the example's prose no longer describes it.
6. **Share links carry the whole document** (`#doc=`, deflate-raw + base64url).
   There is no server and no storage, and a link reproduces exactly.
7. **The viewer gets a browser test in CI.** `site/smoke.mjs` serves `dist/`,
   drives Chromium through the pages, the viewer and one plug-in, and fails on
   any console error or 4xx.

## Current State

- `site/build.mjs` renders README.md, docs/*.md and docs/journal/*.md into dist/, copies viewer/, js/src/, spec/ and docs/img/, and exits non-zero on an unresolved relative link or #anchor (site/build.mjs:58-80, site/build.mjs:202-213)
- `vercel.json` installs with `npm ci --prefix site`, builds with `npm run --prefix site build`, and serves dist/
- `site/smoke.mjs` serves dist/ over HTTP and checks in Chromium the navigation links, the half adder's 4-row relation in the viewer, and plugging AND into NOT; it exits non-zero on any check, console error or HTTP error
- .github/workflows/ci.yml runs the site build and the smoke test in a `site` job; `just site` and `just smoke` run them locally (Justfile)
- `viewer/edit.js` implements plug-in, collapse, compose-all, the library of labelled sub-terms, pretty printing and share-link encoding as pure functions over JSON documents (viewer/edit.js:18-247)
- js/test/playground.test.js tests plug-in, collapse (outer relation unchanged), compose-all, leaf paths, and share-link and pretty-print round trips
- viewer/viewer.js opens the editor column for `?edit`, redraws 250 ms after typing stops, and shows plug-in or collapse controls for the selected star (viewer/viewer.js `setEditing`, `showTools`)
- spec/examples/or-from-nand.json holds OR(A, B) = NAND(NOT A, NOT B) with NAND leaf relations, generated by `or_from_nand` (python/src/wiring_diagrams/examples.py)
- `tsc --strict` checks js/src/ and viewer/ (js/jsconfig.json)

## Missing

- The Vercel project is not created: importing the repository in Vercel is a manual step, and no deployment URL exists yet
- The playground accepts JSON only; stars and wires cannot be drawn or rewired with the mouse
- Plug-in offers only sub-terms of the bundled examples, not sub-terms of the document being edited
- Docs pages have no search and no syntax highlighting

## Divergence

- None found: the README's and docs/visualisation.md's descriptions of the site, playground and smoke test were checked against the code on 2026-10-09
