Wiring diagrams

An example, a term or a bare diagram, in the shared JSON format. The diagram redraws as you type. Output of term.to_json() (Python) or serde_json::to_string(&term) (Rust) pastes straight in.

Python source to scan into a wiring diagram, with the library's own scanner (how code maps to diagrams). Leave the function empty to draw the whole module.

Scroll to zoom, drag to pan. Hover a cable to see everything the composition glues to it. Click a star to see its relation.
